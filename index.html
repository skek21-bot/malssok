🕒 최근 변환 기록

말쏙(MalSsok)은 내장 사전 + 다중 무료 AI + Google Gemini 하이브리드 엔진으로 작동합니다.
모든 기록과 설정은 외부 서버로 전송되지 않으며 사용자의 기기에만 안전하게 보호됩니다.

⚡ 고성능 Gemini 엔진 연결 (선택사항)

기본 무료 AI는 설정 없이 바로 작동하지만, 간헐적으로 느릴 수 있습니다.
무료 Gemini API 키를 등록해 두시면 0.5초 이내 100% 성공률로 작동합니다!

🔑 1분 만에 무료 API 키 받는 방법:
1. Google AI Studio (여기를 클릭)에 로그인합니다.
2. [Create API key] 버튼을 누르고 생성된 키를 복사해 위에 붙여넣으세요.
3. 입력한 키는 깃허브나 외부에 절대 노출되지 않으며 현재 스마트폰/PC에만 암호화 저장됩니다.
